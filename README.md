📖 Features & Architecture

    🧠 Steno Memory (.brain): Saves ~75% context tokens using compressed key-value stenography. Auto-flushes after 10+ steps to prevent context overflow.

    🔌 Dynamic MCP Importer: One-click visual importer for .py and .js MCP server scripts with automatic interpreter detection and zero-zombie process cleanup.

    🌐 Flexible LLM Backend: Native support for OpenRouter, Groq, OpenAI, and 100% offline local LLMs via LM Studio (http://localhost:1234/v1) or Ollama (http://localhost:11434/v1).

    🛡️ 3-Tier Security Concept: STRICT, WORKSPACE_SANDBOX (Recommended), and UNATTENDED.

    🧰 Built-in Toolset: Web search & scraping (Playwright/BS4), Python & Terminal execution, File system management, and Steno-Brain memory state management.
